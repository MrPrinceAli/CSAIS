# Kebijakan keamanan

Jika kamu menemukan celah keamanan (misalnya kebocoran token, bypass tanda tangan portal lembaga,
atau injeksi di halaman web), **jangan buka issue publik**. Laporkan lewat
[GitHub Security Advisories](https://github.com/MrPrinceAli/CSAIS/security/advisories/new).

Sertakan langkah reproduksi dan dampaknya. Laporan akan ditanggapi secepatnya.
